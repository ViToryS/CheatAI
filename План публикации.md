- корректность отображения текста и изображений.

## 2.3 Локализация

В приложении должен присутствовать:

- русский язык интерфейса;
- русский текст описания приложения.

# 4. Подготовка APK-файла

## 4.1 Генерация ключа подписи

```bash
keytool -genkey -v -keystore release.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias alias_name
```

## 4.2 Оптимизация APK

```bash
zipalign -v 4 app.apk app_aligned.apk
```

## 4.3 Подписание APK

```bash
apksigner sign --ks release.keystore app_aligned.apk
```

## 4.4 Проверка установки APK

```bash
adb install app_aligned.apk
```

Необходимо проверить:

- успешную установку;
- запуск приложения;
- работу основных функций.

# 5. Заполнение карточки приложения

## 5.1 Название приложения

Необходимо указать:

| Поле | Значение |
|---|---|
| Название | CheatAI |
| Ограничение | До 30 символов |

## 5.2 Краткое описание

Краткое описание должно содержать:

- основную функцию приложения;
- преимущества приложения.

CheatAI — это Android-приложение для чтения книг в формате EPUB. Оно автоматически выделяет географические названия в книге, показывает их на карте и помогает находить определения незнакомых слов через Викиданные (Wikidata).

## 5.3 Полное описание

📖 Чтение книг: Полноценная читалка с поддержкой формата EPUB на основе движка Readium.
🗺️ Интерактивная карта: Приложение автоматически находит в тексте все географические названия (с помощью NER-модели на сервере), выделяет их и показывает на карте через Yandex MapKit.
📝 Заметки: Создавайте заметки с привязкой к конкретной странице или фразе в книге.
🔍 Быстрый поиск: Ищите значения любых слов и терминов через интеграцию с API Викиданных (Wikidata).
💾 Сохранение прогресса: Приложение автоматически запоминает, на какой странице вы остановились.

## 5.4 Категория приложения

- Книги и справочники

## 5.5 Возрастной рейтинг
