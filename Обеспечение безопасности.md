# Обеспечение безопасности

# 1. Передача данных по сети

Приложение выполняет сетевые запросы к трём внешним сервисам.

| Сервис | Угроза | Защита |
|---|---|---|
| Wikidata API | Перехват запроса, подмена ответа | Запросы выполняются по протоколу HTTPS. Android System WebView и HttpURLConnection/OkHttp автоматически проверяют валидность SSL-сертификата сервера. |
| Яндекс.Карты | Перехват запросов, извлечение API-ключа | Используется официальный Yandex MapKit SDK, который работает только по HTTPS. API-ключ привязан к package name и подписи приложения. |
| Выделение геоназваний (NER) | Подмена ответа сервера | Запросы к NER-серверу выполняются по протоколу HTTPS.  Сервер работает по HTTP (локальный запуск), в production-версии требуется переход на HTTPS с проверкой сертификата. Существующий код сервера используется для демонстраци |

---

# 2. Внутренние риски и атаки

| Сервис | Угроза | Защита |
|---|---|---|
| Извлечение API-ключей | Поиск ключей Яндекс.Карт и MY_IP в APK | Ключи хранятся не в коде, а в файле local.properties и подставляются через BuildConfig |
| SQL-инъекции | Атаки через базу данных | Используется библиотека Room. Все запросы выполняются через DAO-интерфейсы с параметризированными запросами. |
| Запуск вредоносного кода | Уязвимости при открытии EPUB-файлов | Используется проверенная библиотека Readium. JavaScript и внешние скрипты отключены. |

---

# 3. Хранение данных на устройстве ( файлы, базы данных, доступ других приложений)

Приложение использует внутреннее хранилище Android.

| Тип данных | Место хранения | Уровень защиты |
|---|---|---
| EPUB-файлы книг | /files/books/ | Internal Storage приватная папка приложения. Другие приложения не имеют доступа. |
| Обложки книг | /files/covers/ | Приватная папка приложения. |
| Заметки и прогресс чтения | cheatai.db (Room SQLite) | База данных хранится в приватной папке приложения. Защищена шифрованием файловой системы Android (File-Based Encryption). |
| Временные файлы | cacheDir | Автоматически очищается системой при нехватке памяти. Важные данные туда не помещаются. |
