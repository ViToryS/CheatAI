# Монетизация приложения 

##  Аспекты, влияющие на выбор монетизации

| Аспект | Значение | Вывод |
|---|---|---|
| Пользователи | Люди, которые много читают *(преимущественно художественная литература и чтение для развлечения)* – студенты, школьники, любители литературы | Аудитория готова платить за удобство и дополнительные функции |
| Время использования | Регулярно *(ежедневно / еженедельно)* | Можно использовать подписку, так как свойства аудитории приложения подразумевают ежедневное возвращение к книге |
| Проблема, которую решает приложение | Экономит время на поиск информации *(места, определения)* | Пользователь заинтересован в эффективности и удобстве |
| Ключевая ценность | 1. Умный поиск мест на карте  <br> 2. Быстрый поиск определений  <br> 3. Комфортное чтение | Можно ограничить количество запросов в бесплатной версии |

---

#  Расходы и ограничения

| Параметр | Значение | Вывод |
|---|---|---|
| API-ключи Яндекс.Карт | Стоимость зависит от числа уникальных пользователей в день. При количестве более 1000 пользователей требуется переход на платные тарифы | Необходимо компенсировать расходы |
| Поиск определений | Бесплатный | Определения можно предоставлять всем пользователям |
| Сервер с выделением мест | Требует хостинг | Нужно покрывать расходы на хостинг |
| Офлайн-режим | Книги уже находятся на устройстве пользователя | Не требует дополнительных затрат |

> **Итог:**  
> Основные расходы связаны с API-запросами и хостингом сервера, поэтому в бесплатной версии необходимо ограничивать количество запросов.

#  План монетизации приложения

## Выбранная модель

### **Freemium (условно-бесплатная модель) + реклама**

Пользователь может бесплатно пользоваться основными функциями приложения, а подписка снимает ограничения и отключает рекламу.

---

# Бесплатная версия

| Функция | Ограничение |
|---|---|
| Чтение EPUB | Безлимит |
| Заметки | Безлимит |
| Поиск определений | 30 запросов в день |
| Карта мест | 30 запросов в день |
| Реклама | Баннер перед загрузкой книги |

---

# Premium (Подписка)

| Функция | Ограничение |
|---|---|
| Все функции без ограничений | Безлимит |
| Реклама | Отсутствует |

---

# Стоимость подписки Premium

| Тариф | Цена |
|---|---|
| Месяц | **149 ₽** |
| Год | **999 ₽** |

---

# Почему выбрана именно такая модель

- Пользователи смогут бесплатно читать книги и познакомиться с приложением   
- Подписка позволяет компенсировать расходы на сервер и API  
- Отсутствие рекламы в Premium повышает комфорт чтения  
- Годовая подписка мотивирует пользователей оставаться в приложении надолго
