

**CheatAI** — это Android-приложение для чтения книг в формате EPUB. Оно автоматически выделяет географические названия в книге, показывает их на карте и помогает находить определения незнакомых слов через Викиданные (Wikidata).

---

## ✨ Ключевые возможности

*   **📖 Чтение книг:** Полноценная читалка с поддержкой формата EPUB на основе движка Readium.
*   **🗺️ Интерактивная карта:** Приложение автоматически находит в тексте все географические названия (с помощью NER-модели на сервере), выделяет их и показывает на карте через Yandex MapKit.
*   **📝 Заметки:** Создавайте заметки с привязкой к конкретной странице или фразе в книге.
*   **🔍 Быстрый поиск:** Ищите значения любых слов и терминов через интеграцию с API Викиданных (Wikidata).
*   **💾 Сохранение прогресса:** Приложение автоматически запоминает, на какой странице вы остановились.

## Старт


### Установка и запуск проекта

### 1. Клонируйте репозиторий

git clone https://github.com/ВАШ_АККАУНТ/CheatAI.git
cd CheatAI

### 2.  Запуск NER-сервера (бэкенд для поиска мест)

Приложение CheatAI использует отдельный Python-сервер для выделения географических названий из текста глав.

####  Установка зависимостей



Перейди в папку сервера:

```bash
cd D:\CheatAI\server (свой путь)
```

Установи зависимости:

```
pip install -r requirements.txt
```

#### Запуск сервера

В той же папке server выполни команду:

```
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

```

### 3. Настройка API-ключа для Яндекс.Карт

Приложение использует Яндекс.Карты для отображения найденных мест.

#### Получение ключа

1. Перейди на Яндекс.кабинет разработчика 
2. Создай новый API-ключ для сервиса **MapKit Mobile SDK**  
3. Укажи идентификатор приложения: `com.example.cheatai`

#### Добавление ключа в проект

В корневой папке проекта создай файл `local.properties` и добавь:

```properties
MAPKIT_API_KEY="ваш_ключ_яндекс_карт"
```

#### 3.1 Настройка IP-адреса

##### Узнай IP своего компьютера в локальной сети

выполни команду:

```text
ipconfig
```

Найди строку **IPv4-адрес** (например, `197.158.0.105`)

---

##### Добавь IP в файл `local.properties`

В корневой папке проекта создай файл `local.properties` (если его нет) и добавь:

```properties
MY_IP=197.158.0.105
```

Телефон и компьютер должны быть подключены к одной Wi-Fi сети



## 📱 Использование приложения 

---

### 1. Установка приложения

Скачай APK-файл на свой телефон  



### 2. Как добавить книгу

1. Нажми на круглую кнопку с плюсом внизу экрана  

2. Выбери EPUB-файл из памяти телефона  

3. Приложение автоматически подставит название, автора и обложку (если они есть в файле)  

4. При желании отредактируй информацию и нажми «Сохранить»  
<img width="200" alt="Screenshot" src="https://github.com/user-attachments/assets/fcbf4938-a6e1-4595-826b-311ba9657993" />

### 3. Как читать книгу

1. На главном экране выбери книгу  

2. Нажми «Читать»  

3. Листай страницы свайпами по левой/правой части экрана  

4. Двойной тап — показать/скрыть верхнюю и нижнюю панели  

<img width="200" alt="Screenshot_20260424_134831" src="https://github.com/user-attachments/assets/79923a69-2c39-4293-8e98-6bac438bbe17" />

---

### 4. Как искать места на карте

1. Во время чтения нажми на кнопку с картой в верхней панели  

2. Приложение само найдёт в тексте главы географические названия  

3. Найденные слова подсветятся
4. Нажми на нужно слово
5. При успешном запросе карта покажет выбранное место (самый релевантный вариант) 
<img width="200" alt="Screenshot_20260424_134531" src="https://github.com/user-attachments/assets/3ceb7d7a-6a23-418f-96fc-370660c77b84" />

---

### 5. Как искать значение слова

1. Нажми на кнопку с лупой в верхней панели (режим поиска определений)  

2. Выдели слово в тексте (1 слово за раз)  
3. Нажми на галочку

4. Внизу появится определение из Википедии  

5. Можно отредактировать запрос нажав на кнопку "карандаш"
<img width="200" alt="Screenshot_20260424_134625" src="https://github.com/user-attachments/assets/0ce20a16-b09e-4987-9282-a0c1f5275929" />

---

### 6. Как создать заметку

1. Нажми на «Закладки» в нижней панели на странице описания книги или из экрана чтения

2. Нажми на плюс  

3. Введи заголовок и текст заметки  

4. Заметка сохранится и будет привязана к текущей странице или к книге в целом

5. Можно изменить и удалить заметку
